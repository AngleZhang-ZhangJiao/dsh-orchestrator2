# 全局回归 · 用途说明

> **区语义**：跨任务的**全局回归记录**（发布前全量回归：范围 / 用例 / 结果）。
> 位置：`04-测试/全局回归/`（项目级，非任务级）。本文件说明用途与维护规则；具体回归记录按日另建文件。

## 一、放什么

| 内容 | 说明 | 文件命名 |
|---|---|---|
| 全量回归记录 | 本次发布批次的全量用例清单 + 逐条结果 | `全局回归-YYYYMMDD.md` |
| 回归范围声明 | 覆盖哪些任务/模块，明确**未覆盖**的区域 | 同上（范围节） |
| 结果与差异 | 通过/失败/阻塞逐条；与 `测试基线/` 的差异 | 同上（结果节） |
| 回归结论 | 是否放行发布 + 遗留问题清单 | 同上（结论节） |

> **不**放：单任务的人工测试记录（那属于 `04-测试/<TP>/测试记录-YYYYMMDD.md`）。

## 二、谁写、何时写

- **写入者**：调度员。
- **时机**：发布批次回归时（同批次含多个任务、或功能改动可能波及跨任务行为时）。
- **版本规则**：**按日留痕**（`-YYYYMMDD`），同日多轮用 `-YYYYMMDD-N`（N 从 2 起）。

## 三、回归记录必含四节

1. **范围**：本批含哪些任务/包；覆盖的模块与用户路径。
2. **用例**：逐条编号（来源可为各任务验收结论的 AC 汇总）。
3. **结果**：逐条 通过/失败/阻塞 + 证据（命令/截图/记录链接）；**无证据不成结论**。
4. **结论**：放行 / 不放行（+ 遗留问题与处置）。

## 四、与相邻产物的分工

| 产物 | 层级 | 用途 |
|---|---|---|
| `04-测试/<TP>/测试记录-YYYYMMDD.md` | 任务级 | 单包用户实测 |
| `04-测试/<TP>/验收结论.md` | 任务级 | 单包通过结论 + 债务清单 |
| `04-测试/全局回归/` | **项目级** | 批次发布前跨任务全量回归 |
| `04-测试/测试基线/` | **项目级** | 回归对照的基准数据 |
