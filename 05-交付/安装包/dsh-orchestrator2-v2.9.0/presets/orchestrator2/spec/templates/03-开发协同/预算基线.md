# 预算基线（项目级默认预算档）

> 本文件由用户维护（开工时建一次）；**不含任何价格内容**——订阅制不按量付费，无费用概念。
> 任务包预算块（02 文档 §预算块）按此填写；**本文件缺失时按规范内置默认档继续**，并在对应预算台账标注「按规范内置默认档」。
> 修复包（TP-修复N）与场景2 技术调研储备：**只统计不控制**：不设上限，台账照记，用户自行管理。

## 默认预算档（内置，v2.1 按包复杂度分档）

| 项 | 小包（缺省） | 大包 | 说明 |
|---|---|---|---|
| C 运行次数 | ≤4 次/包 | ≤8 次/包 | 含初次执行 |
| B 运行次数 | ≤6 次/包 | ≤8 次/包 | 计划审核 + 代码审查合计（v2.1 验证并入审查后每包每轮省一次）；复杂度审查只加小节不加环节、不额外计数 |
| 调度员工作轮 | ≤24 个/包 | ≤48 个/包 | 每轮=一个真实工作步（B/C 后台派工，看门狗循环在轮内、不烧轮） |

## 分档说明（v2.1）

- **小包** = 轻量改动/单点功能；**大包** = 多处文本/多文件改造、机制级改动、含全文重写或跨模块影响。
- **档位由调度员在任务包生成时标注**（写入任务包 02 §预算块「档位」行），**用户确认**后生效；关卡2 授权前用户可见可改。
- 缺省档 = **小包 4/6/24**；无档位标注时按小包口径执行。
- 范围内现场扩档（小包跑成大包）→ 记入 `决策记录.md`（裁决类）后调整；调整后仍以新档位三项为硬上限。

## 其他口径（不随档位变化）

| 项 | 口径 | 说明 |
|---|---|---|
| 修复循环 | ≤3 轮/问题 | 质量裁决（非预算上限）；同一问题 >3 轮出决策简报 |
| 研究员运行 | ≤5 并行 | 超出分批，02 调研清单注明批次（场景2 逐批拓展不设固定批次数上限） |
| 场景2 技术调研储备 | **只统计不控制** | 台账照建照记（含中断），**不设 C/B/工作轮三项硬上限** |
| 修复包 | **只统计不控制** | 不填预算块上限，台账照记 |
| token 用量 | 仅统计参考 | **不作停机依据**（硬上限只看次数/轮数）；token 硬上限仅待计量落地且口径可信后可选开启 |

## 口径备注

- 硬上限 = C/B 运行次数 + 工作轮三项（**按档位取值**）；**token 用量仅统计参考，不作停机依据**。
- **派工即计次**：凡 B/C 派工点火即记一次运行，含异常返回与用户中断；恢复轮对照工作证据与 git log 对账补记。
- 超限动作：停止推进 → 生成决策简报 → 用户裁决。
- **全程无费用概念**：本文件与台账/预算块不出现费用、价格、折算（「不统计费用」类否定表述允许）。
