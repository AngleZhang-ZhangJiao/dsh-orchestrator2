# 测试基线 · 用途说明

> **区语义**：基准快照与基线数据（性能基线、关键行为基线），供后续版本对照。
> 位置：`04-测试/测试基线/`（项目级，非任务级）。本文件说明用途与维护规则；具体基线数据按批次另建文件。

## 一、放什么

| 内容 | 说明 | 文件命名 |
|---|---|---|
| 性能基线 | 关键操作的耗时/吞吐/内存快照（含采集环境） | `性能基线-YYYYMMDD.md` |
| 关键行为基线 | 必须保持不变的行为（输入 → 期望输出样例、边界行为） | `行为基线-YYYYMMDD.md` |
| 环境快照 | 采集时的运行环境（OS/运行时版本/依赖版本/硬件档次） | 随基线文件内记录 |

> **不**放：某一次任务的实测过程记录（那属于 `04-测试/<TP>/测试记录-YYYYMMDD.md`）。

## 二、谁写、何时写

- **写入者**：调度员或开发员（基线采集时）。
- **时机**：基线建立 / 刷新时（性能优化前后、大版本发布前、关键行为变更前后）。
- **版本规则**：**按批次留痕**——每次采集另存 `-YYYYMMDD` 文件，不覆盖历史基线（否则无法对照）。

## 三、怎么用

1. **对照**：新版本测试时，与本目录既有基线逐项比对，差异超出阈值 → 视为回归，报调度员分级。
2. **全局回归**：发布批次回归（`04-测试/全局回归/`）时以本目录基线为参考基准。
3. **不发明数据**：采集工具不可用时，如实记录「未采集」，不用估计值充数。
