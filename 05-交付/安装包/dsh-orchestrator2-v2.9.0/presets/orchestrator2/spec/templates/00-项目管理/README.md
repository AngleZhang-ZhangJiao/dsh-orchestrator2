# 00-项目管理 · 本区导航与维护规则

> **区语义**：项目级管理平面——跨任务的当前快照、路线、索引、决策、发布规划与规范本体。
> **单任务流程产物不进本区**（任务需求/方案/任务包在 `01-设计/`；状态与工作证据在 `03-开发协同/`；实测在 `04-测试/`；交付物在 `05-交付/`）。
> 与根级 `项目看板.md` 分工：根级看板 = 项目级任务总览导航（人读入口）；本区 `当前状态.md` = 项目快照与结论表。**冲突一律以各任务 `03-开发协同/<任务>/状态.md` 为准。**

## 一、各文件职责与更新时机

| 文件 | 内容 | 写入者 | 更新时机 | 版本规则 |
|---|---|---|---|---|
| `README.md` | 本文件：本区导航与维护规则 | 调度员（建区时一次） | 建区/职责调整时 | 按需修订 |
| `当前状态.md` | 项目当前快照：基线日期 / 产品名 / 代码仓位置+当前 commit / 当前自动开发任务 / 最近闭环任务 / 结论表 / 下一步 | 调度员 | 阶段大迁移、任务闭环、裁决后 | 原地更新（新快照覆盖；旧快照如需留痕入 `90-历史归档/`） |
| `产品路线图.md` | 里程碑与版本路线（M0…/K 系列规划、冻结范围声明） | 用户拍板、调度员落盘 | 路线规划/调整时 | 原地更新 + 重大调整记入 `决策索引.md` |
| `任务索引.md` | 全任务静态登记：编号 / 名称 / 当前状态 / 双区目录链接（设计区 + 协同区）；含已完成任务 | 调度员 | 任务立项、关闭、改名时 | 原地更新 |
| `决策索引.md` | **项目级**决策台账（索引式：DEC 编号 + 标题 + 类型 + 状态 + 详情链接） | 调度员（用户裁决后入账） | 项目级裁决发生时 | 追加（不改写已入账条目） |
| `发布批次规划.md` | 批次规划：功能→批次映射、合并发布裁决、各批次范围与前提 | 用户拍板、调度员落盘 | 批次规划/调整时 | 原地更新 |
| `开发准备.md`（★v2.1.4） | 项目级开发准备记录（固定块五字段：规范版本/必要项/未通过项/最近复查/门禁结论 + 必要项清单表）：首次对话引导探查→用户授权补齐→`enter_auto_mode` 开发准备门禁；**门禁机器解析源** | 调度员（引导探查后落盘；用户裁决类信息由用户确认） | 首次对话引导、配置/仓库/执行位置变化后复查 | 原地更新（`最近复查` 留痕） |
| `项目目录及协同开发规范.md` | 规范本体（项目内版本优先）；脚手架初始化时复制至此 | 调度员（脚手架复制 / 规范升级时） | 立项脚手架 / 规范升级 | 随规范版本 |

## 二、维护纪律

1. **决策三层分工**：项目级裁决 → 本区 `决策索引.md`；设计决策 → `01-设计/设计决策摘要.md`；任务级决策 → `03-开发协同/<TP>/决策记录.md`。**不混写**。
2. **单一权威源**：本区任何文件与任务 `状态.md` 不一致时，以任务 `状态.md` 为准（本区是快照/索引，不是状态机）。
3. **规范本体位置**：规范复制到本区（`00-项目管理/项目目录及协同开发规范.md`），不再放 `03-开发协同/`（v2.1 目录体系演进 F 项）。
4. `项目进度基线.md` 已取消（v2.1）：设计/开发/测试演示进度并入 `当前状态.md`。
